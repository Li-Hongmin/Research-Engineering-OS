\chapter{Git 不是用来“保存代码”，是用来“证明历史”}
\label{ch:git_proof}
\section{分支策略（更适合学术）}
\begin{itemize}
  \item \texttt{stable}：论文可复现版本（只接受经过清单验收的合并）。
  \item \texttt{exp/<hypothesis>}：每条假设一条分支（短命）。
\end{itemize}

\section{关键动作}
\begin{itemize}
  \item 每个“论文候选结论”必须打 tag：\texttt{paper-v0.1}, \texttt{ablation-a1}。
  \item 实验产物不进 git（除非小到可以）；产物用 \texttt{run\_id} 管理。
\end{itemize}
