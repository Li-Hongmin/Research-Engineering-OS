\chapter{从“能跑”到“可信”只差一个 Definition of Done}
\label{ch:dod}
\section{论文候选结论的 DoD（建议原样贴到项目里）}
\begin{itemize}
  \item 一条命令可复现主指标（例如写成 \texttt{make reproduce RUN=<id>}）。
  \item run 记录齐全：commit hash、config、seed、数据版本、环境摘要。
  \item baseline 与 ablation 使用同一评估脚本产生。
  \item 至少一个 smoke test 能在 1--3 分钟跑完（防止后期才发现 bug）。
  \item 结果图/表由脚本生成，不手工拖拽。
\end{itemize}
