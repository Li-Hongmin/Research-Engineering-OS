## 本書について

これは『研究工程 OS』の漫画版であり、生き生きとした漫画ストーリーを通じて、研究開発におけるエンジニアリング実践の課題と解決策を描いています。

主人公の**みなみ**の旅に同行し、一緒に理解しましょう：

- **3種類の技術的負債**：探索負債、検証負債、再現負債
- **基本単位としての実験**：コードではなく実験を思考の基本単位とする
- **証拠としてのGit**：バージョン管理で追跡可能な証拠の連鎖を構築する
- **AI協働ワークフロー**：AI時代に研究の信頼性をいかに維持するか
