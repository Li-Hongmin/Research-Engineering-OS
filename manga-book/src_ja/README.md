## 本書について

『研究工学 OS』の漫画版です。鮮やかなコマ割り形式を通じて、科学研究におけるエンジニアリング実践の課題と解決策をお届けします。

主人公**小研（しょうけん）**の旅に寄り添いながら、以下を探求していきます：

- **三種類の技術的債務**: 探索的債務、検証的債務、再現性的債務
- **実験を基本単位として**: コードではなく実験を思考の基本単位として捉える
- **Gitを証拠として**: バージョン管理によるトレーサビリティの確立
- **AI時代の協働ワークフロー**: AI時代における研究の信頼性維持
