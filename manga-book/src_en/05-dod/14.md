<div class="manga-story-label">DoD Item 2 - Able to explain why it works</div>
<p class="manga-story-content">"The second item is the most critical," the advisor's tone became especially serious. "You must be able to clearly explain why your method works. Not 'it seems to work,' but to be able to argue why it should work."</p>

<p class="manga-story-content">Rina thought of those ablation experiments of hers, and those obscure code comments.</p>

<p class="manga-story-content">The advisor looked at her. “You understand this issue now, don’t you? You ran an ablation experiment, but you can’t explain why deleting one line of code has little impact, while deleting another line of code has a huge impact.”</p>

<p class="manga-story-content">"What does this mean?" a freshman raised his hand and asked.</p>

<p class="manga-story-content">The advisor turned to face everyone. “This means that if a reviewer asks, ‘Why would changing it this way be better?’ you can give a logical answer. If you can’t explain it clearly, then your work doesn’t hold up.”</p>

<p class="manga-story-content">He pointed at Rina. “Rina’s earlier ablation experiments were crucial. By deleting the code line by line and seeing how the results changed, she began to understand what each part did. But that still wasn’t enough—she needed to know *why* each part had that effect.”</p>

<p class="manga-story-content">Xiao Yan raised her head. She had never imagined that that attempt would become so important.</p>

<p class="manga-story-content"><em>💭 From now on, I not only need to make the code produce results, but also understand the purpose of every line. I need to write good comments, design ablation experiments, and be able to prove that every design choice is well-founded. Only then can I confidently say: this isn’t a coincidence—this is a design I understand thoroughly.</em></p>

<p class="manga-story-content">The mentor continued, “This means:</p>

<p class="manga-story-content">- Every design choice should have a rationale<br/>
- Code comments should be clear<br/>
- Ablation studies should be conducted<br/>
- The contribution of each module should be analyzed<br/>
- Ideally, use theory or intuition to explain why this design works"</p>
