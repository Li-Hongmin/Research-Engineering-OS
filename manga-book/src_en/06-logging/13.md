<div class="manga-story-label">Log File Organization</div>
<p class="manga-story-content">Implement log rotation. Previously, Xiaoyan’s log files would sometimes grow without limit and eventually fill up the hard drive. Now she has set rules: each log file is kept to a maximum of 5MB; once it exceeds that, it is automatically compressed and backed up. This both preserves historical records and avoids wasting space.</p>
