<p class="manga-story-content">To speed up the process, her advisor suggested she use an AI assistant to generate a project template. Xiaoyan opened Claude and gave a brief description: “Generate a standard research project template for me, including a directory structure like src/, experiments/, configs/, outputs/, as well as a README and a Makefile.” A minute later, the complete project framework and all the basic files were generated. Looking at the neat list of files on the screen, Xiaoyan recalled that saying—“standing on the shoulders of giants”—and decided that from then on, she would use AI to kick off every new project this quickly.</p>
