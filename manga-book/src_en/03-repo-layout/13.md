<div class="manga-story-label">Quick Start for New Experiments</div>
<p class="manga-story-content">The advisor introduced an important concept: fast variables and slow variables. The code in experiments/ is the "fast variables"—it changes frequently and needs rapid iteration. The code in src/ is the "slow variables"—it should be stable, reliable, and change slowly. These two must not be confused; otherwise the entire project will fall into chaos.</p>
