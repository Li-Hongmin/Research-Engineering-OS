<div class="manga-story-label">The Importance of Testing</div>
<p class="manga-story-content">Add test cases to verify the correctness of AI-generated code. You can’t just look at the code—you need to actually run it. And not just run it once; you need to design a complete set of test cases, including normal cases, boundary cases, and error cases. If the AI-generated code can’t pass the tests, that indicates there’s a problem.</p>
