<div class="manga-story-label">An Introduction to the Six Elements</div>
<p class="manga-story-content">The mentor sketched a hexagon, with each vertex representing a key element of an experiment: code version, data version, configuration, runtime environment, output results, and execution logs. Only then did Rina understand: she had been thinking about the problem of “code,” but what she should really be thinking about is the problem of “experiments.” Experiments are what truly need to be fully recorded and reproducible.</p>
