<div class="manga-story-label">Accountability Turns into Tracking</div>
<p class="manga-story-content">Once, Xiaoyan almost made a fatal mistake. She wrote a config.py that contained an API key and a database password, and almost ran git add by accident. Luckily, her mentor warned her. Once Git commits something, even if you delete the file, it stays in the history forever. Anyone with permission to access the repository can dig those keys back out. Xiaoyan immediately learned to create a .gitignore file to exclude all sensitive information. "Honesty and transparency are good, but protecting your keys is basic security."</p>
