## 关于本书

这是《研究工程 OS》的漫画版，通过生动的漫画故事，讲述科研中的工程实践挑战与解决方案。

跟随主人公**小研**的旅程，一起了解：

- **三种技术债务**：探索债、验证债、复现债
- **实验作为基本单元**：把实验而非代码作为思考的基本单位
- **Git 作为证明**：用版本控制建立可追溯的证据链
- **AI 协作工作流**：在 AI 时代如何保持研究的可靠性
