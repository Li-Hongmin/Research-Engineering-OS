# 附录B：CLAUDE.md 模板

将以下内容保存为项目根目录下的 `CLAUDE.md`，AI 助手会自动遵循这些规则。

---

```markdown
# CLAUDE.md - 研究工程规范

## 项目信息
- 项目: [name]
- 语言: Python
- 框架: PyTorch

## 核心原则

1. **三种债务**：探索债（清理原型）、验证债（必须测试）、复现债（记录环境）
2. **实验六要素**：代码版本、数据版本、配置、环境、结果、日志
3. **AI 是助手**：生成可以快，上线必须慢；看不懂的代码不接受

## 目录结构

```
src/           # 稳定代码（有测试）
experiments/   # 实验代码（可粗糙）
configs/       # 配置文件
tests/         # 测试
outputs/       # 输出（不提交）
data/          # 数据（不提交）
```

## Git 规范

**Commit 格式**: `<type>: <description>`
- `feat:` 新功能 | `fix:` 修复 | `exp:` 实验 | `refactor:` 重构

**规则**:
- 每次改动 ≤200 行
- 功能和重构分开提交
- 不在 main 直接改代码

## AI 生成代码规则

**必须**:
- [ ] 附带验证方式
- [ ] 人工审查核心逻辑（数据处理、模型、评估）
- [ ] 先在实验分支验证

**禁止**:
- 功能+重构混在一起
- 跳过测试直接合并

## 完成的定义（DoD）

- [ ] 结果可复现
- [ ] 能解释为什么有效
- [ ] 与 baseline 公平对比
- [ ] 有测试覆盖
- [ ] 配置已记录

## 每周检查

- [ ] 关键实验能跑通
- [ ] 代码已 push
- [ ] 数据有备份
```
