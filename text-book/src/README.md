## 关于本书

这不是一本教你"如何写代码"的书，而是一本教你**如何管理研究代码**的书。

目标读者：
- AI/ML研究人员
- 计算生物学研究者
- 需要维护实验代码的科研工作者

核心理念：
- **实验才是单元**（不是代码文件）
- **探索可以野，但输出必须可清理**
- **结论可以暂时脆弱，但证据链必须扎实**
