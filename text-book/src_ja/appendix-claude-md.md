```markdown
# CLAUDE.md - 研究エンジニアリング規範

## プロジェクト情報
- プロジェクト: [name]
- 言語: Python
- フレームワーク: PyTorch

## 基本原則

1. **3種類の負債**：探索負債（プロトタイプを整理）、検証負債（テスト必須）、再現負債（環境を記録）
2. **実験の6要素**：コードバージョン、データバージョン、設定、環境、結果、ログ
3. **AIはアシスタント**：生成は速くてもよい、デプロイは慎重に；理解できないコードは受け入れない

## ディレクトリ構成

```
src/           # 安定コード（テスト済み）
experiments/   # 実験コード（粗くてもOK）
configs/       # 設定ファイル
tests/         # テスト
outputs/       # 出力（コミットしない）
data/          # データ（コミットしない）
```

## Git 規約

**コミット形式**: `<type>: <description>`
- `feat:` 新機能 | `fix:` バグ修正 | `exp:` 実験 | `refactor:` リファクタリング

**ルール**:
- 各変更 ≤200行
- 機能とリファクタリングは別コミット
- mainブランチで直接変更しない

## AI生成コードのルール

**必須**:
- [ ] 検証方法を含める
- [ ] コアロジックは人間がレビュー（データ処理、モデル、評価）
- [ ] 実験ブランチで先に検証

**禁止**:
- 機能+リファクタリングを混ぜる
- テストをスキップしてマージ

## 完了の定義（DoD）

- [ ] 結果が再現可能
- [ ] なぜ機能するか説明できる
- [ ] ベースラインと公平に比較
- [ ] テストカバレッジあり
- [ ] 設定が記録済み

## 週次チェック

- [ ] 主要実験が実行可能
- [ ] コードがpush済み
- [ ] データがバックアップ済み
```
